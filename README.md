# KYUDO — Three.js MVP v4.2

ブラウザで遊べる、弓道の近的競技を題材にした3Dシミュレーションゲームです。28m先の36cm霞的を狙い、四射の的中数と矢所を競います。

## 特徴

- Three.jsによる3Dの射場・弓・矢・的の表現
- マウスとタッチの両方に対応したシンプルな操作
- 引分けから会、離れ、残心までを意識した射撃体験
- 四射ごとの的中判定と、的中矢の平均中心距離を表示
- インストール不要の単一HTMLファイル構成

## 遊び方

1. 画面を押したまま下方向へドラッグして、弓を引きます。
2. ドラッグ中に上下左右へ動かし、着弾位置を微調整します。
3. 十分に引いた状態で少し静止すると、矢所がまとまりやすくなります。
4. 指またはマウスボタンを離すと矢を放ちます。
5. 四射を終えると結果が表示されます。「もう一度射る」で再挑戦できます。

## 実行方法

`index.html` をWebブラウザで開いてください。ローカルサーバーを使う場合は、プロジェクトのルートで次のように起動できます。

```bash
python -m http.server 8000
```

その後、ブラウザで <http://localhost:8000> を開きます。

> [!NOTE]
> Three.jsをCDNから読み込むため、プレイ時にはインターネット接続が必要です。
